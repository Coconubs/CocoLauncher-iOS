# CocoLauncher iOS

Launcher Minecraft: Java Edition cho iPhone/iPad, cài sẵn cho server **Coco Cobblemon**.

## Cài đặt

- Trang cài: https://coconubs.github.io/CocoLauncher-iOS/
- Nguồn SideStore: `https://coconubs.github.io/CocoLauncher-iOS/source.json`
- File IPA: [Releases](https://github.com/Coconubs/CocoLauncher-iOS/releases)

Cần:
- Tài khoản Microsoft đã mua Minecraft: Java Edition.
- Cài bằng SideStore hoặc iloader (ESign/KSign không chạy được) và bật JIT bằng StikDebug.
- Khuyên máy 8 GB RAM.
